# 判客规则细则

## 可配置参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| report_valid_days | 7 | 报备有效期（天） |
| protect_days | 30 | 首访保护期（天） |
| followup_gap_days | 15 | 超期无跟进视为放弃 |
| related_match | 是 | 是否启用关联人合并 |

## 归属优先级
1. 有效报备（审核通过且未过期）→ 报备人
2. 无有效报备 → 首访接待销售
3. 保护期内复访 → 原归属人，保护期顺延（每次复访 +7 天，上限 60 天）
4. 保护期外且无有效跟进 → 释放公客，重新首访者获得归属
5. 关联人命中 → 按最早登记记录归属

## 飞单风险规则
| 编号 | 风险类型 | 判定条件 | 权重 |
|---|---|---|---|
| F1 | 无报备成交 | 成交但全流程无有效报备 | 高 |
| F2 | 渠道冲突 | 渠道报备后由自然客成交，或反向 | 高 |
| F3 | 跨项目撞客 | 同客户在多个项目同时登记 | 中 |
| F4 | 关联人规避 | 以配偶/亲属名义重新登记绕开保护期 | 高 |
| F5 | 分销洗客 | 报备信息与到访人身份不一致 | 高 |
| F6 | 体外成交 | 房源不在系统 / 收款账户异常 | 高 |
| F7 | 保护期内抢单 | 他人在保护期内成交同一客户 | 中 |

## 等级映射
- 命中 ≥1 条高权重 → 高风险（建议冻结佣金并复核）
- 仅命中中权重 → 中风险（要求补证 + 主管复核）
- 无命中 → 低风险（正常结算）
- 证据不足 → 待复核（不输出结算结论）
